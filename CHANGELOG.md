## [1.0.0] — 2026-08-01

### 🎉 Initial Open Source Release

#### Added
- **Schema-Driven Form Builder:** Generate interactive AcroForm PDFs directly from a 3-sheet Excel configurator workbook or an AI-generated JSON schema file.
- **Automatic Multi-Column Grid Layouts:** 1 to 4 column layouts generated automatically per section.
- **8 Field DataTypes:** `short_text`, `long_text`, `whole_number`, `decimal`, `date`, `choice`, `multi_choice`, `radio_choice`.
- **Built-in Validation Rules:** Per-field validation operators with built-in PDF automation enforcement and red highlight warnings.
- **Live Summary Generator:** Embedded Acrobat JavaScript button generates a formatted `Label: Value` summary of all fields inside the PDF.
- **Form Lock / Unlock Control:** One-click button locks or unlocks all form fields to prevent accidental edits after completion.
- **Clear / Reset Form:** Resets all fields to their default initial state.
- **Batch PDF Data Consolidator:** Scans a folder of completed PDFs and exports all form data to a structured Excel report.
- **AI-Ready JSON Import:** Import form schemas generated by any modern AI assistant (ChatGPT, Gemini, Copilot, etc.).
- **Desktop GUI (Tkinter):** Multi-tab GUI with About tab (6 Core Features), Sheet 1/2/3 configuration tabs, Batch Consolidator tab, and Session Logs tab.
- **Export / Import Config:** Save and reload form configurations as Excel workbooks.
- **Standalone .exe:** Pre-compiled Windows executable — no Python installation required for end users.
- **Mathematically Centred Button Labels:** Button captions centred using `pdfmetrics.stringWidth()` calculations.
- **MIT License:** Open-source under the MIT License.
- **Employee Information Record Template:** Ships with a ready-to-use Employee Information form as the default demo.
- **HELP_USER_GUIDE.html:** Built-in interactive HTML user guide with all features, comparison matrix, and quick start guide.
