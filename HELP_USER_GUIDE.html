🚀 2. Overview & System Purpose

The Schema-Driven Interactive PDF Form Suite is a modern desktop application that enables users to design, generate, fill, and consolidate interactive fillable PDF forms without needing complex server setups or paid PDF editing software.

📝 Part A: Form Designer & Compiler

Allows form administrators to easily configure form titles, headers, grid layouts (1 to 4 columns), section titles, and form fields in a simple graphical interface, compiling them into interactive PDF forms with 1 click.

📊 Part B: Batch PDF Data Consolidator

Scans folders containing completed PDF forms submitted by users, extracts all filled form field data automatically, and exports a clean, formatted Excel consolidation report.

Default sample form: The application ships with a ready-to-use Employee Information Record template covering fields like Full Name, Employee ID, Date of Birth, Phone, Email, Department (dropdown), Designation, Joining Date, Salary, Residential Address, and Emergency Contact — giving you an immediate working demonstration out of the box.

⚡ 4. Step-by-Step Quick Start Operating Guide

  1. Launch Application: Double click Interactive_PDF_Generator_Suite.exe located in the Interactive_PDF_Code folder.
  2. Explore the About Tab: The first tab (ℹ️ About) displays the 6 Core Feature cards and quick-action buttons — a handy reference at any time.
  3. Configure Form Details: Switch to Sheet 1 — Basic Form Details to set your Form Title, Subtitle, Instructions, and initial Lock Status.
  4. Define Layout Sections: Use Sheet 2 — Section Layouts to add or edit form sections and assign 1 to 4 grid columns per section.
  5. Define Form Fields: Use Sheet 3 — Field Configuration Schema to configure labels, data types, default values, and choice dropdown options.
  6. Export & Backup Configurations: Click 💾 Export Config to save your current form configuration into a custom Excel backup file (e.g. My_Form_Template.xlsx) for safe-keeping or sharing.
  7. Import Existing Configurations: Click 📂 Import Config to load any previously saved 3-sheet Excel template file directly into the GUI, or import an AI-generated JSON schema.
  8. Generate Fillable PDF Form: Click the primary button ⚡ Create Fillable PDF Form. The PDF will be saved in Interactive_PDF_Code/Interactive_PDF/ and automatically opened in your PDF reader.
  9. Consolidate Completed Forms: Switch to the Batch PDF Data Consolidator tab, select the folder containing filled PDFs, and click 📊 Run Data Consolidation into Excel Report.

📑 5. GUI Tabs & Features Explained

ℹ️ About (First Tab)

Displays the 6 Core Feature cards with emoji icons and descriptions, providing a quick reference to the software's capabilities. Also contains shortcut buttons to open this Help Guide and the GitHub repository. New in v1.0

📋 Sheet 1: Basic Form Details

Configures global header banners, instruction points (1–3), footer banner text, and default form lock status (Locked, Unlocked, or Not Required).

📑 Sheet 2: Section Layouts & Grid Columns

Manages section layout architecture. Section_ID (e.g. SEC_1, SEC_2) is protected systematically. Users can customize section heading titles and assign 1 to 4 grid columns per section.

⚙️ Sheet 3: Field Configuration Schema

Data grid where all form fields are defined. Field_ID and Section_ID are protected to preserve data integrity. Edit labels, pure data types, default values, validation operators, parameter values, and choice dropdown options.

📊 Batch PDF Data Consolidator

Browse any target folder containing filled PDFs and extract form field data row-by-row into a formatted Excel report saved directly inside the target PDF folder.

📄 Session Logs & Diagnostics

Displays a live dark-mode console output and provides a 1-click button to open session log files (logs/log_YYYYMMDD_HHMMSS.txt) for troubleshooting.

🔢 6. Supported Field Datatypes & Validation Operators

Field DataType Allowed Validation Operators Description & Format Rules
short_text none, min_length, max_length Single-line text entry field.
long_text none, min_length, max_length Multi-line scrollable text area for summaries or progress narratives.
whole_number none, =, <, >, <=, >=, in_range, out_range Integer numbers only (e.g. 10, 45).
decimal none, =, <, >, <=, >=, in_range, out_range Floating-point decimal numbers (e.g. 150.5, 2.75).
date none, date_ddmmyyyy, =, <, >, <=, >=, in_range Date entries formatted strictly as DD-MM-YYYY.
choice none Interactive PDF dropdown choice menu. Options entered as comma-separated values (e.g. Option 1, Option 2, Option 3).
multi_choice none Multi-select Checkboxes [ ] allowing form fillers to check 1, 2, 3, or all options simultaneously. Summarized as comma-separated labels or NIL.
radio_choice none Mutually Exclusive Radio Buttons ( ) for quick single-select choices (e.g. Yes, No). Summarized as chosen label or NIL.

✨ 7. Advanced Interactive PDF Features

  • Live Summary Generator: Inspects all 8 data types live inside a PDF Reader when clicking >>>> Click the Button To Generate Summary <<<<. Outputs clean Label: Option A, Option B or NIL for empty/unselected fields.
  • Form Locking/Unlocking: Built-in button controls dynamically lock or unlock all textboxes, comboboxes, checkboxes, and radio buttons to prevent accidental modifications after completion.
  • Clear Form (Reset): Resets text fields, dropdowns, checkboxes, and radio buttons back to clean initial states (evaluating to NIL in summary).
  • Mandatory System Instructions: System-locked red instruction points explicitly warn users to click 'Generate Summary' before saving and emailing PDFs.
  • Standard AcroForm Compatibility: Native AcroForm compatibility ensures reliable data extraction during batch consolidation, regardless of PDF reader software used.
  • AI-Ready JSON Import: Any AI assistant (ChatGPT, Gemini, Copilot, etc.) can generate the standard JSON schema, which is directly importable into the GUI — enabling rapid form prototyping.
  • Centered Action Buttons: Button labels (Generate Summary, Reset Form, Lock/Unlock) are mathematically centered using font-metric calculations so they render correctly in all PDF readers. Fixed in v1.0
